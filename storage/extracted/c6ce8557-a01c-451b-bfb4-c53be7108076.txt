Course overview (2)

❑ Roughly speaking, anything that carries information can be 
considered a signal: speech, ECG, VN index, …
❑ Plotted against time, which is called an independent variable
➢ A signal may have more independent variables, e.g. pictures, videos, …
What is signal?

❑ Any physical device/computer program is considered a system 
➢ if the application of a signal to the device or program generates a new signal.
❑ Objective: build a system to produce desirable outputs
➢ System analysis: given the input & system, what will be the output?
➢ System synthesis: given the input & desired ouput, what will be the system?

➢ Time scaling, reflection, time shifting
